# 构建多架构镜像

buildkit、buildctl 和 buildx 分别是什么：

* **buildkit**：是一个用于构建容器镜像的构建引擎，是 docker 的底层构建器。buildkit 并不是直接使用的工具，它的用法是作为构建引擎被其他工具调用，比如 docker
* **buildctl：**是用于和 buildkit 进行交互的 cli 命令行工具，用于直接跟 buildkit 交互

* **buildx：**是 docker 用于和 buildkit 交互的子命令，为 docker 提供了基于 buildkit 的构建能力，它增强了 build 的构建能力（比如多结构构建
